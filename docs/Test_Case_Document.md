## Registration workflow update

The EMS retains the external Google Form URL. Attendees must declare submission using `externalFormSubmitted: true`; the backend stores `external_form_submitted`. EMS cannot independently verify form responses. Name and email are copied from the authenticated user, while phone, college and department are validated from the request. Registration creates a confirmed registration, pending payment record and UUID ticket/QR in a transaction; notification storage follows commit on a best-effort basis.

A valid event body supplies title, venue, ISO local start/end times and capacity; optional description/category/URLs/deadline use validator limits. Use generated UUIDs, never shared real-user data.
